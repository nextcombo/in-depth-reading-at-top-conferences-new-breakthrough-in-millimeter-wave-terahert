Colleagues and students in millimeter wave/tHz communication and MU-MIMO research, it is likely that you have encountered a core issue: how to balance high spectral efficiency with low computational complexity when selecting beamforming? Although exhaustive search can achieve optimal performance, it has become "ideal for the laboratory" due to excessive computational overhead. Existing low-complexity algorithms often suffer from performance degradation or lack of scalability, especially in scenarios of ultra-large MU-MIMO for 6G.
Let's start with the research background: Why is it so difficult to achieve a "spectral efficiency-computational power" balance in beam selection? In the 5G-A/6G technical system, millimeter waves (mm-Wave) and terahertz (THz) are the core frequency bands for achieving ultra-high bandwidth and ultra-high data rate. However, MU-MIMO beamforming is a key technology for enhancing spectral efficiency and supporting multi-user spatial multiplexing. But when they are combined, beam selection faces dual challenges:
1  
Channel Characteristics-induced Interference Challenges: Millimeter Wave/Terahertz channels feature high path loss, narrow beamwidth, and sparse multipath characteristics. A slight deviation in the beam direction can lead to a significant performance drop, and beam interference among multiple users is even more difficult to suppress, demanding extremely precise beam selection.
2  
Algorithmic Design of Computational Constraints: In traditional beamforming algorithms, the SVBS (Singular Vector Beamspace Search) serves as a performance upper bound, achieving optimal spectral efficiency. However, its exhaustive search mode takes approximately 162 seconds to achieve single-channel results, completely failing to meet the real-time demands of practical systems. Meanwhile, another classic algorithm, IOSVB (Interference Optimized Singular Vector Beamforming), despite reducing complexity through candidate matrices, still employs a one-time combination search. In scenarios with multiple users and data streams, it still struggles with high iteration counts and computational overhead.
In essence, existing algorithms either "perform at the top of their game but suffer from insufficient computational power," or "reduce computational burden but compromise performance." Finding a balance between these two aspects that is both theoretically rigorous and practically applicable has become the key research focus in this field. The core contribution of this paper precisely addresses this issue.
Core Innovation Dissection: From Theory to Algorithm, Tackling the Challenge with Dual Approaches
Innovation 1: Reconstructing the theory of interference quantification in MU-MIMO, allowing beam selection to have a "precise optimization goal" for algorithm design. The most feared is "optimizing based on experience," but this paper first establishes a precise quantitative model for inter-user interference in MU-MIMO through a layered mathematical deduction of theorems, corollaries, and lemmas, completely overcoming the limitations of empirical design.
1  
The user interference can be directly represented by channel singular vectors and singular values, which transform the complex interference calculation into the operation of beam-related matrix, greatly simplifying the definition of optimization objective.
2  
This proves the core conclusion that the total system interference equals to the square norm of non-diagonal elements in the beam correlation matrix — meaning that the optimization objective for beam selection can be precisely defined as "minimizing the non-diagonal elements of the beam correlation matrix," providing a clear and quantifiable direction for subsequent algorithm design.
The significance of this theoretical framework lies in its provision of a universal paradigm for interference analysis for all similar beam selection algorithms, not only supporting the design of the G-IOSVB algorithm but also laying a solid theoretical foundation for subsequent related research. This is at the core of an excellent top-tier conference paper: it not only solves one problem but also offers a set of methods.
Innovation 2: Inventive iterative restructuring of search logic, transitioning from "exhaustive" to "stepwise optimization", achieving exponential reduction in computational power. The G-IOSVB algorithm builds on the foundation of IOSVB but introduces a revolutionary restructuring in its search strategy—replacing the "exhaustive exhaustion of all combinations in the candidate matrix" of IOSVB with Nₛ steps of greedy iteration search (Nₛ represents the number of data streams for each user). The core logic can be summarized as "select the best, discard the selected, control gain", which achieves a three-step reduction in computational load.
1  
Stepwise Optimization: Each iteration only selects the optimal beam (U users) from the beam-related matrix, transforming the original large-scale combination search into multiple small-scale single-column searches. The search space is exponentially reduced.
2  
Exclude Selected Columns: After each iteration, the selected beam columns are removed from the candidate set. Subsequent iterations search only in the remaining columns, avoiding redundant calculations and further reducing the search space.
3  
Gain Threshold Constraint: Introducing the channel gain threshold γ (experimentally verified optimal value is 0.6), ensuring that each selected beam meets the minimum gain requirement, avoiding performance loss due to greedy selection, and allowing "computing power reduction" without sacrificing "performance metrics."
At the same time, the algorithm employs Hadamard product to update the relevant matrix, retaining only the candidate beam information for the current iteration without storing the full matrix, further reducing memory and computational overhead. The essence of this design lies in transforming combinatorial complexity into iterative complexity, which grows linearly, far lower than the exponential growth of combinatorial complexity, which is also the core reason for the significant computing power advantage of G-IOSVB algorithm in large-scale scenarios.
Innovation 3: Precisely quantify the computational complexity, and mathematically prove the "scalable nature of algorithm advantages". Outstanding algorithm design inevitably involves rigorous complexity analysis. This paper excels in this aspect:
1  
A closed expression for the number of iterations in G-IOSVB is derived, combined with Fermat's Last Theorem and Bernoulli numbers to simplify the formula. This enables precise quantitative analysis of computational complexity, providing a mathematical basis for the algorithm's computational advantage.
2  
Defined the computation gain ratio (G-IOSVB vs. IOSVB iterations), proving that the algorithm's computational advantage increases exponentially with the number of candidate columns R_sel, data flow Nₛ, and user count U.
This conclusion is crucial as it means that the G-IOSVB algorithm is not only effective in small scenarios but also adaptable to the application needs of 6G ultra-large MU-MIMO, demonstrating strong scalability—a characteristic highly valued in engineering implementations.
